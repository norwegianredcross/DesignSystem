# DatePicker (Calendar)

#### `DatePicker` er den visuelle kalenderkomponenten som lar en bruker velge en dato. Den er en valgfri forbedring av manuell datoinntasting.

Kalenderen vises først etter at JavaScript er initialisert. Bruk alltid et navngitt
`DateInput` (eller et annet egnet datofelt) utenfor kalenderen når brukeren skal
sende inn en dato. Feltet og vanlig skjemainnsending skal fungere uten JavaScript.
`DatePicker` sender ikke inn en skjemaverdi på egen hånd.

Importer `rk-designsystem/styles` i konsumentens layout. Komponentene injiserer
ikke CSS ved kjøring. Siden kan være en serverkomponent; bare komposisjonen som
kobler `onDateSelect` til feltets state trenger en klientgrense.

`Date`-props tolkes fortsatt i nettleserens lokale tidssone. Kalenderen rendres
ikke på serveren, slik at ulike tidssoner ikke gir hydration-avvik i kalenderen.
En ugyldig `selectedDate` behandles som ingen valgt dato. Hvis også `initialDate`
er ugyldig, åpnes inneværende måned. Dette er ikke en konvertering til tidssoneuavhengige kalenderdatoer. Konsumenten
eier servervalidering og eventuell tjenestespesifikk tidssone.

## Bruk

```tsx
import { DatePicker } from 'rk-designsystem';
import { useState } from 'react';

// For å bruke kalenderen, må du håndtere state selv.
const MyCalendar = () => {
  const [selected, setSelected] = useState<Date | null>(new Date());

  return (
    <DatePicker
      selectedDate={selected}
      onDateSelect={setSelected}
      initialDate={new Date()}
    />
  );
}
```

#### Komponenten er en kontrollert kalendervisning. Du må tilby en `selectedDate` (den valgte datoen) og en `onDateSelect`-funksjon for å fange opp når brukeren velger en ny dato.

## Retningslinjer

#### Bruk `DatePicker` når brukere trenger en visuell måte å velge en dato på, i tillegg til å skrive den manuelt.

#### Gjør dette
 * **Synkroniser state:** Sørg for at `DateInput`-verdien og `DatePicker`-valget er synkronisert.
 * **Bruk `initialDate`:** Sett `initialDate` til den valgte datoen (hvis den finnes) slik at kalenderen åpnes på riktig måned.

#### Unngå dette
* **Ikke for tid:** Denne komponenten er kun for å velge dato (dag, måned, år).
* **Ikke uten `onDateSelect`:** Komponenten er ubrukelig med mindre du lytter til `onDateSelect`-hendelsen for å lagre brukerens valg.

## Tilgjengelighet

* **Grid:** Ett tabstopp, fullstendige ukedagsnavn og `aria-selected` på valgt dato.
* **Tastatur:** Piltaster flytter én dag/uke, Home/End går til ukens start/slutt,
  PageUp/PageDown bytter måned og Shift+PageUp/PageDown bytter år. Enter eller
  mellomrom velger en dato. Tab forlater den inline kalenderen.
* **Navigasjon:** Månedsvelgerne har navn, og månedsoverskriften annonserer endringer.
* **Plass:** Alle sju kolonner tilpasses tilgjengelig bredde, også i en smal kolonne
  på en bred skjerm. Fokus og valgt dato markeres også i forced-colors-modus.
