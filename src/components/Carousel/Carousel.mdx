# Carousel

#### Et fleksibelt bildegalleri. Du sender inn bildene via `images`‑propen. Piler og prikker er innebygd. Layout og farger følger design tokens.

<Primary />

<Controls />

---

## Bruk

```tsx
import { Carousel } from 'rk-designsystem';

const images = [
  { src: 'https://.../image-1.jpg', alt: 'Beskrivende alt-tekst 1' },
  { src: 'https://.../image-2.jpg', alt: 'Beskrivende alt-tekst 2' },
  { src: 'https://.../image-3.jpg', alt: 'Beskrivende alt-tekst 3' },
];

// Minimal
<div style={{ width: 900, height: 520 }}>
  <Carousel images={images} />
</div>

// Autoplay
<div style={{ width: 900, height: 520 }}>
  <Carousel images={images} autoPlay autoDelay={4} />
</div>
```

#### Tips
- Sett eksplisitt bredde/høyde på containeren for å styre aspekt og layout.
- For piltaster brukes `Button icon`-stil og NAV-ikoner i tråd med øvrige komponenter.
- Tokens for farger, mellomrom og radii brukes i CSS‑modulen.
- Vil du lese bilder fra Supabase? Se historien “WithSupabase” – den henter bilder og sender dem inn via `images`.

## Testet HTML-baseline

Uten JavaScript er alle bilder tilgjengelige i et galleri som kan rulles.
Tab flytter fokus mellom bildene og bringer dem inn i visningen. Bilder og
alternativ tekst er også tilgjengelige hvis stilarket mangler.

Når stilarket og JavaScript er klare, aktiveres Embla og kontrollene vises.
Testene dekker sen hydrering, bevart fokus og bildeposisjon, manglende CSS
før og etter hydrering, redusert bevegelse og bruk fra en pakket Next.js-server-side.

Autoplay er av som standard. Redusert bevegelse stopper autoplay og
animerte overganger. Tastaturfokus stopper autoplay til brukeren starter den igjen.
Når både piler og bildevelger er slått av, beholdes det native galleriet uten autoplay.

Forbruker-fixturen importerer `rk-designsystem/styles` for det forbedrede
karuselloppsettet. Ingen ekstra kopi av CSS injiseres ved kjøretid.
